# Лаба 1. Git

## Что сделано
1. Создала папку с тестовым проектом и инициализировала репозиторий (`git init`).
2. Посмотрела статус файлов (`git status`).
3. Добавила файлы в индекс (`git add .`).
4. Указала имя и почту (`git config`).
5. Сделала первый коммит (`git commit -m "Первый коммит"`).
6. Посмотрела историю (`git log`).
7. Создала репозиторий на GitHub, добавила SSH-ключ.
8. Подключила удалённый репозиторий (`git remote add origin ...`) и отправила коммиты (`git push`).
